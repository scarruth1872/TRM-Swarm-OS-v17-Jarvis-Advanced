## 40. Jarvis won't start — port 3000 is in use?

An orphaned tsx child process is likely holding port 3000. Find and kill it: first run 'netstat -ano | grep :3000' to find the PID, then 'powershell -Command "Stop-Process -Id <PID> -Force"' to kill it. Then restart with 'npm run dev'.

---

## 41. Jarvis can't reach the TRM swarm?

Jarvis connects to TRM via 127.0.0.1:8021 (not localhost — Node resolves localhost to IPv6 ::1 which TRM doesn't bind). Check that all URLs in server.ts use '127.0.0.1:8021' and that TRM is actually running.
