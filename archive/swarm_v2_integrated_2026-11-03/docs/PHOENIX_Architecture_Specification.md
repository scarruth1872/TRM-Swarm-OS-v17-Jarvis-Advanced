- **Objective:** Eradicate sanctuary autoreactive B-cell populations in bone marrow and CNS compartments
- **Delivery Constraints:** Blood-brain barrier traversal, marrow homing, minimal off-target cytotoxicity

### Phase 2 – Athena Shield

- **Targets:** TLR7 and IFN-α transcripts
- **Duration:** 75-day transient silencing window
- **Purpose:** Create a clean maturation niche for newly generated B-cells

### Phase 3 – Hera Watch
- **Sensors:** In vivo aptamer biosensors monitoring 5-marker Cure Fingerprint (sCD25, CXCL10, Anti-dsDNA, plus two additional undisclosed markers)
- **Feedback Loop:** Automated micro-dose re-trigger of Phase 2 shield upon relapse signature detection

## 4. Architectural Trade-offs
- **Modularity:** Each phase is independently updatable via new nanoparticle formulations.
- **Robustness:** Multi-layer redundancy (eradication + shielding + monitoring) reduces single-point failure.
- **Scalability:** UTP mechanisms designed for parallel deployment across multiple autoimmune indications.
- **Observability:** Continuous biomarker telemetry enables longitudinal efficacy tracking.
