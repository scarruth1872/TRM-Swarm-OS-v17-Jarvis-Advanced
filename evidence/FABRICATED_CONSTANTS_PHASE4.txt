3. THE AUTHORITATIVE NON-FABRICATED SOURCE
====================================================================
Derivation (single source of truth), trm_uefi_kernel/host_council_server/src/
voltage.rs:

    Phi_V = (V_core/1.25)^2 * (f_actual/4000) * (V_ddr/1.35)
            * max(0.5, 1 - mem%/200)

The divisors 1.25 V (core) and 1.35 V (DDR) are NOMINAL references, deliberately
not the rails themselves, so the rail terms are not structurally inert.

Exposed at GET http://127.0.0.1:8022/system/voltage with a `measured` flag.

Read live for this evidence file (2026-11-03):
  {"phi_v": 0.6884, "measured": false,
   "voltage_rails": {"v_core": 1.1, "v_ddr": 1.2},
   "cpu_clock_mhz": 4000.0, "memory_percent": 0.0,
   "source": "FALLBACK: one or more telemetry reads failed; values are nominal,
              NOT measured"}

measured=false is correct and expected: this box has NO voltage sensor (no
LibreHardwareMonitor, no OpenHardwareMonitor, no HWiNFO). The rails reported are
the public nominal 1.10 V core / 1.20 V DDR and the clock/memory reads failed,
so the server refuses to call the result a measurement.

Arithmetic re-checked independently:
  (1.1/1.25)^2 * (4000/4000) * (1.2/1.35) * max(0.5, 1 - 0/200) = 0.6884
i.e. 0.7744 * 1.0 * 0.8889 * 1.0 = 0.688356... -> 0.6884. The endpoint's value is
reproducible from the documented formula; it is DERIVED, not read.

5. WHY THIS IS NOT A FABRICATION
====================================================================
- Neither file asserts a voltage number. Neither contains a numeric voltage
  literal any more; both read the doctrine endpoint at run time.
- The only number they can emit is computed by the documented formula from the
  rails the host reports, and it travels with measured=false. The artefact text
  calls it DERIVED, so it cannot be cited as a reading.
- When the source is unavailable both fall back to null / omission, never to a
  constant. No code path in either file can produce a stand-in number.
- The forbidden literal is gone from both files, so no new artefact can carry
  it; the historical value survives in the errata record instead of in code.

Transient note: during verification the first call to read_phi_v() returned None
(endpoint miss) and later calls returned 0.6884. The fallback branch handled the
miss correctly, which is the intended behaviour and is why the null path is
documented above.
