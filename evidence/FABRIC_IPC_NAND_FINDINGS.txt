   arena is consulted, so the arena is a COLD-START text cache, not a hot-path
   win. It holds 9.3 MB of raw JSON that is never re-read after warmup.

   clones all 5 sets. Reaching <1 ms needs &Value borrows, not clones.
3. My earlier claim "mmap the JSON -> <1 ms" was WRONG. This module cannot map
   files. It is a bounded string arena.
4. Rust<->Python IPC is still HTTP-over-TCP. memory_mapped_ipc is in-process
   only; cross-process needs an OS primitive (named pipe / real shared mem).
5. TRM inference is still device="cpu". 2.571 TFLOPS measured on the 6700 XT
   remains idle.
