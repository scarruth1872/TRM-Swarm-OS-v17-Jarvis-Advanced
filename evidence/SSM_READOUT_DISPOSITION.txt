1. BAYES CEILING — ARITHMETIC
  Model: observed label y = true label t with prob 1-p, else uniform over the
  other K-1 classes. Best possible predictor of a fresh re-run label is t, so
      max agreement = (1-p) + p/(K-1)
  p = 0.19:
      K=3 (approve/abstain/reject): 0.81 + 0.19/2 = 0.9050
      K=2 (approve/reject):         0.81 + 0.19/1 = 0.8100
  If 0.19 is read as a between-run disagreement rate rather than a per-run flip
  probability, the per-run flip p0 solves 1-[(1-p0)^2 + 2(p0/2)^2] = 0.19:
      1.5 p0^2 - 2 p0 + 0.19 = 0  ->  p0 = 0.1029  ->  ceiling 1-p0 = 0.8971
  So the noise ceiling is 0.90 (0.81 in the binary view), i.e. 0.32 ABOVE the
  0.583 always-majority baseline. Label noise cannot be the reason a read-out
  fails to clear 0.583; there is 0.32 of headroom under the ceiling.

  Measured flip rate in the current ledger, per field, over all repeated runs of
  the same (topic,agent):
      llm_trit   0 / 2730 pairwise comparisons = 0.0000   (84 cells, 0 flip cells)
      vote       7099 / 35056 = 0.2025                    (322 cells, 58 flip cells)
      ssm_trit   530 / 2730 = 0.1941                      (84 cells, 48 flip cells)
  The 19% figure is the instability of `vote` and of `ssm_trit`, not of the
  council judgement `llm_trit`, which is exactly reproducible on this slice
  (split-half pair agreement 70/70 = 1.000). `vote` is downstream of
  decision_path, which is downstream of the SSM, so part of the 19% is produced
  by the SSM being in the vote path rather than being irreducible label noise.
  With p=0.000 on the actual target the ceiling is 1.000.

3. VERDICT
RETIRE: ceiling is 0.905, baseline is 0.583, no read-out clears it — not because
the label is too noisy (the noise ceiling sits 0.32 above the baseline, and the
measured flip rate on llm_trit is 0/2730), but because the SSM fields carry no
verdict signal: ssm_mean alone scores 0.488 against a 0.583 baseline, and the
only fits that clear the baseline are driven by the LLM's own confidence.

  To make it load-bearing: the ledger needs proposals that differ in substance
  within a topic (the current 6 topics are 3-16 resubmissions of one sentence
  each, so the label is constant per topic) and a target that is not the LLM's
  own confidence — i.e. per-proposal verdicts with measurable within-topic
  variance, on which a content-bearing feature can be tested for within-topic
  discrimination rather than topic recall.
