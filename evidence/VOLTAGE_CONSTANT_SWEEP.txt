DEFECT
------
0.9115 was presented as a measured/telemetry value ("Phi_V = 0.9115 coherence",

REAL SOURCE OF Phi_V
--------------------
trm_uefi_kernel/host_council_server/src/voltage.rs (functions sample()/phi_v()):

    Phi_V = (V_core / V_CORE_NOMINAL)^2
          * (f_actual / F_BASE_MHZ)
          * (V_ddr / V_DDR_NOMINAL)
          * max(0.5, 1 - mem_pct/200)

    V_CORE_NOMINAL = 1.25 V, V_DDR_NOMINAL = 1.35 V, F_BASE_MHZ = 4000
    rails read via Win32_Processor.CurrentVoltage (tenths of a volt) and
    Win32_PhysicalMemory.ConfiguredVoltage (mV); clock via WMIC
    CurrentClockSpeed; memory load via WMIC OS Free/TotalVisibleMemorySize.
    Rounded to 4 dp. `measured` is true only if ALL FOUR reads succeed.
