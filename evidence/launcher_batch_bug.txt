ROOT CAUSE: the platform launcher never worked - a 2-char batch bug

         daily cron health report showed ANOMALY_DETECTED.

  scheduled task 'TRM-Swarm-OS-Microkernel' runs START_TRM_PLATFORM.bat
  at logon. Last Run 9/11/2026, Last Result -2147024894 (0x80070002).
  It has FAILED SILENTLY for ~1 month.

BISECT (minimal repros):
  echo Starting (Release Binary)...   FAILS '... unexpected at this time'
  echo Starting (Release Binary)      OK
  echo Starting Release Binary...     OK
  => ')' immediately followed by '...' inside an if/else block breaks cmd.
     4 such lines existed, one per step. Step 2 is the first, so the
     launcher aborted before starting ANY service.

FIX:
  1. removed ')''...' from the 4 echo lines inside if/else blocks
  2. absolute paths: PY_EXE=...Python311\python.exe, NPM_CMD=...nodejs\npm.cmd
     (Task Scheduler has a minimal PATH - bare python/npm are absent there)
  3. added logs/platform_launch.log so it can never fail silently again
