### 2.2 Mamba-3 Linear State Space Model

The core computational engine is Mamba-3, a linear state space model (SSM) that replaces traditional Transformer attention mechanisms with constant-memory O(1) state recurrences. For a sequence of length N, the SSM evaluates:

$$h_t = \\overline{A} h_{t-1} + \\overline{B} x_t$$
$$y_t = C h_t + D x_t$$

Where $h_t \\in \\mathbb{R}^{d\\_state}$ is the hidden state vector (d_state = 128), $x_t \\in \\mathbb{R}^{d\\_model}$ is the input, and $\\overline{A}, \\overline{B}, C, D$ are learnable parameters discretized from continuous-time dynamics. Critically, the memory footprint remains fixed at 8,192 bytes (128-dimensional state × 32-bit precision × 2 states), independent of sequence length — unlike transformer attention which scales as O(N²d).
