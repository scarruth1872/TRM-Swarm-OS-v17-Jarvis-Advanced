## 4. What it is (capability map)

- **Sovereign runtime** — Native Rust microkernel v20.0.0, UEFI boot, fully offline/private, no
  outbound telemetry, no HTTP IPC, secrets never leave the host.
- **Token-free retrieval** — packed 2-bit hyperdimensional (HDC) recall over five knowledge stores,
  not an LLM API call.
- **Self-governing** — a 15-agent PBFT council grounded in the Monad ("all is one, I am because we
  are") that deliberates and seals every change.
- **Real research, not demos** — 9 ChEMBL drug leads (LpxC/BamA/FtsZ) with real structure + triage
  (7 drug-like, 2 blocked by Lipinski MW>500); 45,911 sealed screening leads (1M screened); 9 proven
  theorems; 403,803 antibodies; clinical-variant ACMG classification.
