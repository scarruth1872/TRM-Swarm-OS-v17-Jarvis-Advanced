## 🛠️ How to Trigger the Master Demo:

```powershell
Invoke-RestMethod -Uri http://localhost:8021/swarm/cra/amplify -Method Post -Body '{
  "problem": "Synthesize Autonomous High-Frequency Telemetry Gateway with Multimodal Safety and Formal Verification",
  "roles": ["Reasoning Engine", "Architect", "Lead Developer", "Security Auditor"]
}' -ContentType 'application/json'
```

### Option B: Via Interactive Dashboard
1. Open Swarm Dashboard at `http://localhost:5183`
2. Navigate to **Tab 19 GENERATIVE ARCHITECT**
3. Paste the prompt into the **Microservice Synthesizer Studio** and click **Synthesize Microservice**.
